# TFIM GNN N=6 to N=8 T=2.5 Evaluation

Source artifact: `artifacts/20260616_193419_tfim_gnn_n6_to_n8_T2p5_eval/`.

This directory summarizes the longer-time T=2.5 evaluation of the N=6-to-N=8 GNN generator.

## Files

- `diagnostics_T2p5.json`: diagnostic summary for the T=2.5 evaluation.
- `summary_by_method_T2p5.csv`: method-level downstream metrics at T=2.5.
- `n8_T2p5_evolution_results.csv`: per-instance N=8 evolution results at T=2.5.
- `comparison_T1p5_vs_T2p5.csv`: comparison between T=1.5 and T=2.5 results.
- `mean_fidelity_T1p5_vs_T2p5.svg`: mean-fidelity comparison plot.
- `n8_T2p5_per_instance_fidelity.svg`: per-instance final-fidelity plot.
- `n8_T2p5_fidelity_distribution.svg`: final-fidelity distribution plot.

The evaluation scripts and code snapshot are kept in the source artifact bundle.
