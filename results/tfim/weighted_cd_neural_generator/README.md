# TFIM Weighted-CD Neural Generator

Source artifact: `artifacts/20260616_161635_tfim_weighted_cd_neural_generator/`.

This directory summarizes the neural weighted-CD generator experiment for random TFIM instances.

## Files

- `fit_metrics.json`: train/validation/test coefficient-prediction metrics.
- `summary_by_method.csv`: downstream evolution metrics by method.
- `test_evolution_results.csv`: per-instance evolution results on the test set.
- `coefficient_scatter.svg`: exact-vs-predicted coefficient scatter plot.
- `per_instance_fidelity.svg`: per-instance final-fidelity comparison.
- `test_fidelity_distribution.svg`: test-set fidelity distribution.

The trained model, labels, and code snapshot are kept in the source artifact bundle.
