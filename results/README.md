# Curated Results

This directory contains figure-ready and paper-facing summaries derived from selected full artifact bundles.

The intended separation is:

- `artifacts/`: full audit trail, including code snapshots, diagnostics, reports, and raw run outputs.
- `results/`: curated summaries used to inspect or regenerate the manuscript-level results quickly.
- `manuscript/data/`: compact plotting inputs and caches used by the manuscript figure scripts.

## Contents

- `c6_average_total_time/`: Rydberg MIS C6 per-total-time protocol selection.
- `c10_t30/`: Rydberg MIS C10/T30 supplemental protocol summary and focused-cache data.
- `xxz/`: XXZ paper reproduction and LBI-designed schedule/catalyst/CD searches.
- `tfim/`: random TFIM weighted-CD neural and graph-neural generator results.

Each subdirectory includes a local `README.md` describing the source artifact bundle and the role of the copied files.
