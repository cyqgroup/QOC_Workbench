# XXZ Delta=1 Schedule Search

Source artifact: `artifacts/20260609_155720_xxz_t3_delta1_schedule_search/`.

This directory summarizes the LBI-designed Delta=1, T=3 XXZ schedule/catalyst/CD search.

## Files

- `best_schedule_strategy.json`: best selected strategy and baseline comparison.
- `plot_rows.json`: compact rows used for plotting the XXZ comparison.
- `schedule_scan_coarse.csv`: coarse candidate scan.
- `schedule_scan_refined.csv`: refined candidate scan.
- `nfad_schedule_comparison.svg`: schedule-comparison figure from the artifact bundle.

The full methods report and code snapshot are kept in the source artifact bundle.
