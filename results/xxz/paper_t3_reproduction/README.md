# XXZ T=3 Paper Reproduction

Source artifact: `artifacts/20260608_171738_xxz_paper_T3_reproduction/`.

This directory contains the reproduced XXZ T=3 baseline protocols used before LBI search.

## Files

- `reproduction_results.csv`: reproduced metrics for SA, SA+AH, SA+CD, OI, OI+AH, OI+CD, and OI+AH+CD across Delta values.
- `optimized_parameters.json`: optimized auxiliary-field/CD parameters from the reproduction run.
- `run_config.json`: numerical and optimizer settings.
- `xxz_t3_protocol_results_report.html`: human-readable reproduction report.

The full code snapshot is kept in the source artifact bundle.
