# XXZ Delta=0.5 Wide LBI Search

Source artifact: `artifacts/20260625_155541_xxz_t3_delta0p5_wide_lbi_search/`.

This directory contains the curated Delta=0.5, T=3 wide LBI search results.

## Files

- `experiment_summary.json`: baseline metrics, search counts, and selected improved strategies.
- `coarse_candidates.csv`: coarse candidate table.
- `refined_candidates.csv`: refined candidate table.
- `refined_candidates_with_sine.csv`: refined table after additional sine-family evaluation.
- `top4_improved_for_plot.csv`: absolute top four candidates above baseline.
- `diverse4_improved_for_plot.csv`: best improved candidates from distinct LBI-designed families.
- `xxz_delta0p5_top4_improved_metrics.png`: top-four summary plot.
- `xxz_delta0p5_diverse4_improved_metrics.png`: diverse-family summary plot.

The full PDF versions, scripts, and code snapshots are kept in the source artifact bundle.
