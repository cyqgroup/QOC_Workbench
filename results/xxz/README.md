# XXZ Curated Results

This directory collects the manuscript-facing XXZ results in one place. The full audit bundles remain under `artifacts/`.

## Subdirectories

- `paper_t3_reproduction/`: reproduction of the T=3 XXZ paper baselines for Delta values 0.5, 1.0, and 1.5.
- `delta1_schedule_search/`: Delta=1 LBI schedule/catalyst/CD search result used for the main XXZ comparison.
- `delta0p5_wide_lbi_search/`: Delta=0.5 wide search with top and diverse improved strategies.
- `delta1_windowed_cd/`: endpoint-windowed CD check for Delta=1, ensuring the CD correction vanishes at the endpoints.

These files are copied summaries from their corresponding artifact bundles so that all paper-level XXZ results are discoverable under `results/xxz/`.
